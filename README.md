# Сайт с мини-играми
## О проекте
Учебный сайт с интерактивными играми, созданными с помощью JavaScript.
## Технологии
- HTML5
- CSS3
- JavaScript
- Git и GitHub
## Реализованные игры
- Простая арифметика.
- Викторина.
- Переворачивание текста.
- Камень, ножницы, бумага.
- Изменение цвета страницы.
- Генератор случайных цветов.
## Запуск проекта
Для запуска проекта локально нужно открыть файл `index.html` через Live Server.
## Демо
Ссылка на опубликованный сайт будет добавлена после настройки GitHub Pages.
## Особенности
- Обработка действий пользователя.
- Проверка введённых данных.
- Адаптивное отображение сайта.
- Интерактивные элементы на JavaScript.
